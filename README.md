# ReaderBuildSS14_Image
Программа для чтения .yml файлов из билдов и извлечения из них изображений.
**! Для работы требуется** [Python](https://www.python.org/downloads/) **и любой билд сервера, например билд** [Corvax](https://github.com/space-syndicate/space-station-14) **!**

# Установка
Требуется установленный [Git](https://git-scm.com/) и [Python](https://www.python.org/downloads/), желательно версии 3.14 (на других я не проверял).
1. Создайте папку в любом месте.
	1. Нажмите на путь к папке вверху проводника.
	2. Введите cmd и нажмите enter, откроется обычный терминал.
	<img width="562" height="296" alt="image" src="https://github.com/user-attachments/assets/fe6550ae-ef19-453a-a461-b5cbb2a3427e" />
	
2. Используйте команду `git clone https://github.com/TORGOVEC471/ReaderBuildSS14_Image.git`
	<img width="487" height="255" alt="image" src="https://github.com/user-attachments/assets/bd2a322e-297e-43ad-95ec-f42a952f60bb" />
	
3. Перейдите в папку `cd ReaderBuildSS14_Image`
	<img width="488" height="256" alt="image" src="https://github.com/user-attachments/assets/08cb87c6-4829-4242-9a59-52b381ae18d2" />
	
4. Введите `pip install -r requirements.txt`
	<img width="488.5" height="256.5" alt="image" src="https://github.com/user-attachments/assets/c51f8bc3-316b-4844-9d0f-22e15c9299df" />
	
5. Запустите `start.bat` и подождите.
	1. Или введите `python UI.py` в консоли чтобы запустить интерфейс.
	<img width="561.5" height="295" alt="image" src="https://github.com/user-attachments/assets/e013872a-f488-4415-b4b3-29f58b451cf9" />

	
# Работа
Вам остается только зайти в настройки и ввести путь до двух папок:
- Папки сохранения спрайтов и анимаций (точка сохраняет всё в папке проекта)
- Папки билда сервера (где должна находиться папка `Resources`, внутри которой `Prototypes` и `Textures`)
